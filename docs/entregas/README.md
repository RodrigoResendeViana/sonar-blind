# Relatórios das matérias (rascunhos)

Um rascunho por matéria, já com o que está construído no repositório. Para cada um:

1. Preencha a capa (grupo, integrantes, links do repositório e do vídeo).
2. Troque cada `[PRINT: ...]` pela imagem pedida e cada `[PREENCHER: ...]` pelo resultado medido.
3. Revise o texto com as palavras de vocês e confira contra o enunciado da matéria (critérios e pesos).
4. Exporte para PDF.

| Matéria | Rascunho | Onde estão os detalhes técnicos |
|---|---|---|
| Visão computacional | [visao-computacional.md](visao-computacional.md) | `visao/`, `edge/` |
| IA generativa | [ia-generativa.md](ia-generativa.md) | `ia/`, `api/sonar_api/ia.py` |
| RPA | [rpa.md](rpa.md) | `rpa/` |
| Maker Lab | [maker-lab.md](maker-lab.md) | `firmware/`, `docs/maker-lab.md` |
| Secure DevOps | [secure-devops.md](secure-devops.md) | `infra/`, `.github/`, `docs/` |

O problema e a visão geral são os mesmos em todos; o que muda é o recorte de cada matéria.
